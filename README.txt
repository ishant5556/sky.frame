SKY.FRAME — FREE STATIC PORTFOLIO

HOW TO PREVIEW:
Open index.html in Chrome. Internet is needed for the sample images and Google Fonts.

HOW TO UPLOAD TO GITHUB:
1. Unzip SKYFRAME-website.zip on your computer.
2. Open your GitHub repository: https://github.com/ishant5556/sky.frame
3. Click "uploading an existing file" (or Add file > Upload files).
4. Drag the FOUR files INSIDE the skyframe-site folder into GitHub: index.html, style.css, script.js, projects.js (README.txt optional).
5. Click Commit changes.
6. Repository > Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main / (root) > Save.
7. Wait for GitHub to publish; expected URL: https://ishant5556.github.io/sky.frame/

HOW TO CHANGE PROJECTS:
Edit projects.js in GitHub (pencil icon). Each entry has name, location, cover and photos.
You can upload your own photos to an images folder and replace sample URLs with paths like images/villa/01.jpg.
To replace the main hero image, edit the .hero-bg background URL in style.css.
To update contact email, edit hello@example.com in index.html.

NOTE: The images are third-party sample images hosted by Unsplash and require internet. Replace them with your own photography before presenting this as your work. This site has no admin dashboard; edits are made through GitHub files.
